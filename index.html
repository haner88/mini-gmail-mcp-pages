Mini Gmail MCP

通过 Gmail API，让个人 AI 助手按你的要求查找邮件、读取邮件、整理草稿，以及向指定收件人发送邮件和附件。

本工具供开发者个人使用。此网站仅提供应用介绍和数据处理说明，不提供登录、邮箱连接或邮件上传功能。

它能做什么

  • 搜索和读取你已授权的 Gmail 邮件。
  • 创建、查看和修改邮件草稿。
  • 按你的指令发送邮件和本机附件，并核对已发送记录。

数据如何使用

邮件组件运行在使用者自己的 Mac 上。Gmail API 处理邮箱请求；用户所选的 AI 服务可能接收完成任务所需的邮件内容和工具结果。发送时，指定收件人会收到邮件正文及附件。详情见隐私说明。

由你控制授权

邮箱访问需要通过 Google 授权。你可以在 Google 账号中撤销访问。此工具不要求把 Gmail 密码输入本网站。
