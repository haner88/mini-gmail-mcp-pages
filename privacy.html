隐私说明

更新日期：2026 年 10 月 18 日。本文说明 Mini Gmail MCP 个人邮件工具及本说明网站的数据处理方式。

访问哪些数据

仅在使用者授权并提出任务后，邮件组件通过 Google Gmail API 访问完成任务所需的邮件标题、发件人与收件人、正文、附件及邮件状态。发送附件时，还会读取使用者指定的本机文件。

当前申请的权限为 gmail.readonly（读取与搜索）和 gmail.compose（管理草稿与发送邮件）。后者包含真实发送能力。

数据流向哪里

  • Google：处理 OAuth 授权、Gmail 查询、草稿和发送请求，并保存邮箱中的邮件。
  • 使用者的 Mac 与 AgentDock：运行邮件组件，处理指定附件及工具结果，并可能保留任务记录、日志或验收证据。
  • 使用者所选的 AI 服务：为理解指令和完成邮件任务，可能接收邮件内容、附件内容或工具结果。相应会话的存储、删除和数据使用还取决于该服务条款及账号设置。
  • 指定收件人：发送成功后收到正文与附件，并按其邮箱服务的规则保留副本。

用途与限制

Google 用户数据仅用于使用者明确发起的邮件功能，不用于广告、出售或数据交易。本工具不授权将通过 Google API 获取的数据用于训练或改进通用 AI 模型。使用者应选择符合该要求的 AI 服务和账号设置。

本工具对 Google API 数据的使用应遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保存、删除与撤销

OAuth 凭据保存在使用者 Mac 的专用私有目录，不会发布到此网站或网站源仓库。使用者应保护本机、账号和凭据，不向他人共享授权文件。

邮箱邮件由 Google 保存；本机任务记录和 AI 会话可能单独保留，撤销邮箱权限不会自动删除这些已有记录。使用者可分别删除相关邮件、本机记录和 AI 服务中的会话。发给收件人的副本需向收件人请求删除。

你可以在 Google 账号的第三方连接中撤销本工具访问，随后停用本机组件并删除其本机授权文件。撤销后需要重新授权才能继续使用。

本网站

本网站是静态说明页面，不设置登录表单，不接收邮件或附件，不使用应用自建的分析脚本或广告。托管方 GitHub Pages 可能为安全目的记录访问者 IP 地址，详见 GitHub 隐私声明。
